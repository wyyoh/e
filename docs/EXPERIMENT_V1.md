# 第二问全局最优验证：第一轮真实执行记录

日期：2026-09-24；仓库：wyyoh/e；版本：Q2-GLOBAL-VERIFY-V1。

## 1. 本轮准确结论

上界UB=5903.038154628秒（已有25架次可行解），下界LB=5362.081790509秒。因而在继承的物理与执行流程模型下，第二层目标满足：

`5362.081790509 <= T* <= 5903.038154628`。

以UB为分母的证据差距为9.164033%。这是上下界未闭合的区间宽度，不是声称实际解刚好比最优差9.16%，也不是原问题求解器已经给出了MIP gap=9.16%。第一层加权迟到已有0可行解，非负性证明其全局最优值为0；后续只考察零迟到解集合法。尚未证明最小完成时间，更未证明后续能耗、架次数的词典序最优。

## 2. 输入、继承与版本管理

输入取自《D题_第二问_ALNS对照与可复现代码.zip》最新时间优先结果。包含80个真实箱号、15个服务区、3类机型、8架运输机、14组电池。数据以instance.json保存，保留原始Excel和DEM的SHA-256。240条有向几何航段沿用已验证数值快照，本轮未声称重新读取DEM逐像元提取。

原能耗关系：`L(q)=L0-(L0-LF)(q/Q)^1.5`，`Ehor=Euse*d/L(q)`，`Eup=(m0+q)*9.81*h/(eta*3600000)`。其文献推导和标准航程标定沿用上游；本轮做优化证明，不重新替换物理定义。准备流程仍是先分配满电能源，再开始准备、装载。改变该流程后，当前模型的最优性结论不能自动沿用。

## 3. 完整架次枚举规模测试

把目的地、货物类型、重量、体积、首批标志、原始时限和优先系数完全相同的箱子归为等价类，共62类；仅按物理目的地/箱型合并为53类。严格62类的有界多重集DP，对重量和体积范围完整计数，使用Python任意精度整数，不存在64位溢出：

|型|容量合格货箱多重集|
|---|---:|
|A|13,639|
|B|55,247|
|C|148,208,452,808|

这些数还没有考虑访问排列、能源可行性、时间窗和排程。不能将其误称为完整可行架次列数；也不能从原始组合大直接证明经严密支配剪枝后必然仍不可枚举。本轮据此切换动态定价，而没有分配数百亿对象内存。

上条建议中“可安全去掉同一趟重复访问”的论证不充分：一方面山区航段物理成本不自动满足普通欧氏VRP的捷径性质，另一方面把第二次交付全部提前到第一次，会增加首次交接时长，可能影响中间紧急交付。原题没有明示每趟各区至多一次，本轮全局下界定价允许重复访问，不依赖这一尚未证明的剪枝。用于寻找上界的有限路线池保留基本访问路线，但其限制不会被偷换为下界条件。

## 4. 第一个下界：完整工作量列生成

设某列r交付a[j,r]个第j类箱子，机型g，作业时长p[r]。放松箱级时限、电量、充电及个体时间互斥，保留全80箱的数量、重量、体积和机型工作量：

- 每类覆盖：sum_r a[j,r] x[r] = demand[j]。
- 机型工作量：sum_{r:type=g} p[r] x[r] <= aircraft[g] T。
- x[r]>=0，T>=0。

不限制一个服务区只访问一次；允许在列内超出某种箱的实际数量，因此可行域是原问题的超集。初始列少量，利用对偶变量寻找负约化成本的运输序列。定价的质量/体积状态严格增加，构成有限DAG，可完整动态规划。第一个模型生成1699列，14轮停止，完整定价没有遗漏负约化成本；经向下取整与整数证书得到LB=4744.953198281秒。

## 5. 加强下界：能量下界与单次停靠有界货量

保留逐载重q的能耗单调结构，对给定图的飞行时间和各q能耗分别取最短路径下界。二者不要求由同一实际路径同时实现，这是**放松**而不是新增实际路线。真实路线的时间、能耗均不小于各自的下界。

时间项下取到1毫秒；能源项分别测试10Wh、1Wh和0.001Wh格，逐项向下取整，能量预算向上取格。这里的离散化只用于降低成本、放宽可行域的**下界模型**；没有对真实飞行时间四舍五入或拉伸轨迹。

加强版对每次停靠枚举该服务区真实箱量范围内的所有非空交付组合，但仍允许重复访问和不同停靠累计超用同类箱，后者由松弛覆盖等式在总量上制约。无箱货物释放、不增加机型、不混用容量。不施加个体排程、时限和电池复用约束。

从返航端反向扩展，状态为累计交付质量、体积、当前节点及能量下界；同一状态保留(能量,约化成本)非支配标签。加入一个前面的停靠时，后继航段载荷正好是现有后缀货重；最终补入O01出发航段。即使只剩负的候选，也必须完整完成该模型的定价，不能把“只搜到一些列”当作收敛。

|放松模型|验证后LB/秒|
|---|---:|
|容量＋机型工作量|4744.953198281|
|再加10Wh能源下界|4894.310924756|
|再加1Wh能源下界|4899.267875928|

能源格再缩小没有提升这次得到的界，说明当前主要缺口不能仅靠更细能量离散解决。

## 6. 整数对偶证书，不直接信任LP状态

LP的对偶形式为：对每一列，sum_j pi[j]a[j,r] <= mu[g]p[r]；mu>=0，sum_g n[g]mu[g]<=1。则sum_j demand[j]pi[j]是下界。

将对偶系数固定为整数比例，使用整数定价成本重新检查完整松弛列空间；若存在负约化成本，统一减小每箱对偶价格，以非空列至少包含1箱的事实修正。已保存证书的三个机型最小整数约化成本分别为1205312、450680、1026536，均非负。

最终证书目标是精确有理数 `5362113963 / 1000006` 秒，即5362.081790509257秒。该整数比较针对保存并复核的下界系数成立；原DEM、浮点物理公式的测量或表示误差不被称为形式化实数证明。所有可行性/最优性范围以文献参数化模型和固定数值输入为前提。

定价C++另与30组随机微型问题的完整前向枚举交叉检查，均一致；证书重检的12个结构、系数、整数定价检查通过。不是用试验个数替代对偶推导。

## 7. 整数主问题与精确排程：已尝试，但没有新可行上界

从定价产生的模式中筛出真实物理可行、需求不超量、单次访问各区的路线，再加入完整单点模式和已知可行上界，构成1163列候选池。该池**不完整**，仅用于寻找新的可行解。

整数主问题保留53类货量覆盖、逐架无人机的总作业负载分配，以及电池工作量减去最多库存数量末次充电尾段的必要条件。90秒限时：status=1，选中25趟，工作量目标5743.171986670秒；求解器池内下界5433.773541907秒、池内gap5.38724%。这两个池内值不能提升原问题的全局LB或UB。

随后建立该25趟的连续时间MILP：359变量、2197约束，分别为飞机与电池分配类型兼容资源，保持完整占用不重叠；采用累计交付数约束匹配原箱最早截止，不改变每箱字段。120秒限时：status=1，未找到可行调度，也未证明不可行。另一个启发式可行起点构造的最小迟到仍大于0，未被接受。

因此：
- 不将5743.17秒当作新上界；
- 不把status=1写成不可行；
- 不添加“禁止这组路线”的不可行割；
- 当前UB仍是经过独立复核的5903.038154628秒。
