# V6 重放的可移植性审计

本次为主干整合重新检查了完整V6归档，原归档及其2934项清单完整，1243项V5文件未改变。

原 `run_v6.py reproduce` 实际运行到V5基线的独立物理、通信与Q4验证通过后，因4份通信JSON的端点浮点时间末位变化而触发严格字节对比失败。失败日志保留在本合入包的validation目录。不能把这次原入口失败记为原入口成功。

新增的仓库级可移植重放不修改归档、不修改原验证器，也不修改任何计划。它调用原重放，从紧凑决策完整重建，运行原物理、能源、资源、连续区间、临界端点以及Decimal严格Q4验证，之后独立对比。通信时间仅容许最多4 ULP且不超过1纳秒的表示差；真实验证失败或非时间末位差异仍中止。

这仅分离“文件序列化是否位级相同”和“物理方案是否可行”，不更改连续通信判据、不删除短区间或边界点、不降低资源冲突判断精度。
