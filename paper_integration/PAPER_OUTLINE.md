# 论文组织蓝图（当前V7/V6口径）

建议题目：**山区洪涝救援中无人机运输—通信协同调度与独立资源配置**。

中心论证：单架次安全不等于多任务可及时完成；运输可执行不等于全过程通信可用；共享资源池可执行不等于独立任务组库存充足。

## 1 问题重述与结构分析
场景、货箱、异构机队、能源与通信；四问新增约束与继承关系；总体求解与证据路线。

## 2 模型假设、符号与评价口径
区分题面给定、模型解释、求解策略与历史敏感性。Q1累计作业时间与Q2/Q3并行makespan不是同一指标。

## 3 数据处理与统一物理—资源模型
原始字段核验 → AEQD → DEM完整经过像元 → 三阶段飞行 → 逐段剩余载荷 → 能耗 → 准备/装卸/交接 → 两阶段充电。中继转场采用hover-compatible高度：`H_R=max(terrain_peak+50, hover_z, O01_z)`；普通运输航段规则不变。

## 4 Q1：单点安全能力与精确组批
18架次下界闭合；59.131296 kWh；精确组批、Pareto与返航余量临界事件。

## 5 Q2：多点运输与共享电池调度
正式23架次零延误方案，5693.231489 s、66.214460 kWh。V7认证：`5433.956428 <= T* <= 5693.231490 s`，UB归一化gap 4.554093092%。22架次见证只说明“更少架次不等于更短工期”。

## 6 Q3：连续通信与中继联合调度
完整轨迹区间/端点 → 中继位置、高度、服务窗口与资源联合排程 → 连续时间精修 → 独立验证。

正式V6/time：
- 23运输+4中继；
- 5836.969929 s；
- 68.939416 kWh；
- 最小硬余量360.867 s；
- 17,756项完整检查与36,672个独立点检查失败0。

关键机制：关键C型任务必须切到西侧中继的相对时刻由956.974 s推迟到1039.150 s，同时西侧中继提前5.821 s就绪，两项合计解释约87.998 s的同模型改善。

鲁棒备选：+0.25 dB完整可行方案5866.140527 s / 69.031751 kWh。旧5755点四中继下界和旧+0.50/+0.55 dB只属于历史release。

## 7 Q4：固定V6日程后的独立资源配置
关联块：S001 / 其余13区 / S006。

- K=2：3种合法分区；需求[4,2,3,6,4,4,2,3]，缺口[0,0,1,0,0,0,0,0]，总缺口1。
- K=3：唯一严格分区；需求[5,2,5,7,4,6,2,3]，缺口[1,0,3,1,0,2,0,0]，总缺口7。

旧relay-copy/N-1/Pareto敏感性未针对V6重跑，只作历史。

## 8 综合讨论与证据边界
连续能力→离散组批；资源接续→系统工期；通信服务切换→运输最早开工；组织边界→共享链断裂。严格区分完整可行验证、全局上下界、有限搜索和历史敏感性。
