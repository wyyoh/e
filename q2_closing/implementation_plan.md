# Q2 封口优化实施计划

基线分支：research/q2-proof-cuts-v4，提交 97187484cdf90ee3f90e194679ce231e97c0baa2。
隔离分支：research/q2-closing。只新增 q2_closing，不改写既有研究与发布结果。

1. 解包并校验不可变输入；对照原始附件和已验证 Q1 物理公式。V4 仅有任务定义，重新构造满足同一上界的完整资源排程，明确区别于历史排程。
2. 重新计算 23 趟的时间、能耗、载荷、箱号、时限，以及飞机和电池链。先发布瓶颈诊断与前五个重构任务集合。
3. 定向生成涉及 B 型的 1/2/3-route、机型替换、箱交换、两/三点联合路线；以机型工作量和精确分配下界筛选，再做连续时间飞机/电池调度。
4. 另记录 <=22 趟可行性研究；有限邻域未找到不可称为全局不可行。
5. 候选使用完整真实物理参数；最终候选从原始 DEM 重建所用航段，与优化器独立 replay 验证。任一差异则不接受。
6. 找到严格改善且全面核验通过的上界即停止主搜索。否则完成所列有界邻域后收口，不扩展全局证明树。
7. 保存源码、种子、日志、逐箱分配、双重核验、四幅图和论文可用报告。分阶段提交。

空间口径沿用以 O01 为中心的 WGS84 AEQD 平面直线；原始 DEM 为 PixelIsPoint，正确转换像元边界。能耗为题面的 3/2 航程律加附加爬升，逐站卸货、空载返回；无下降附加能耗。准备前分配满电电池，电池占用持续至返航后的分段充电完成。

下界 5411.2162 s 作为 V4 已发布证书结论引用，本轮不重跑大规模下界定价。任何继承声明与本轮实际重新核验明确区分。
