## 关键证明边界

实际方案仍用原时间、原能耗。下界侧将时间向下取整到毫秒、能耗向下到1Wh，再取最短路闭包；预算向上取整。每个原合法架次都可以映射成不更耗时、不更耗电的松弛路径。重复访问允许，不使用原题的一次访问假定。纯经停通过闭包放松；真实箱级期限和详细排班不在根LP中。

对每种机型的全部非空松弛列，反向资源标签定价计算全局最低整数约化成本。需求对偶必要时向下修复，再用分子/分母构造有效界；不直接把有限主问题目标当成全局界。每个未搜索区域仍保留在树的全局最小界中。

另外做了5条子集行割和60分钟截止前工作量前缀实验：前者根界5384.770405秒，后者本次无额外改进。这些辅助源代码和完整日志在配套计算包中；不要把不同实验的下界提升相加。三种定价器24个微型实例各与独立前向穷举比较，共72次相同。

固定23个任务后，B型任务分给2架飞机的工作量下界5693.231489秒已被实际方案达到。这只证明固定任务排班最优，不是全问题下界。

## 运行

需要 Python 3.10+、NumPy、SciPy 和支持C++17的g++。

```bash
python -m pip install numpy scipy
python verification_v3/code/run_all.py --solve --nodes 500
```

入口复用父仓库已有的canonical input snapshot及其哈希，不重新抽取DEM，不修改原始物理参数；复制到本版数据目录后核验23架次CSV。源代码为普通Python/C++文件，没有新增压缩代码载荷。

主入口重算根列生成、500节点树、独立前向小例、全树覆盖与重定价；`results/status.json`始终区分上下界和未证全局最优。首次运行需要`--solve`；配套完整证据包已有树文件时可不加。时间限制或平台数值差异可能影响搜索前沿，不承诺所有环境的求解路径和字节相同。

完整节点证书、上界逐箱/逐段/资源表、辅助实验及旧证据复核日志随本轮计算包提供；仓库上述命令可以重新生成核心下界证据。代码不自动改Q1、Q3、Q4，也不合并到main。

当前最重要的未完成工作：完整路线整数化与真实飞机—共享电池精确排程的有效反馈。不能把部分整数树或某一个固定候选子问题的最优性当作原问题全局最优。
