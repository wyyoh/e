# 下界包含性与证书范围

## 1. 原问题不变

实际可行解采用既有文献推导的水平能耗Euse*d/L(q)、爬升附加(m0+q)*9.81*h/(eta*3600000)、题面L(q)的3/2次幂及20%储备。逐段剩余载荷、精确飞行时间、整批交付完成时刻和准备前满电流程不变。本轮继承已核验的240条地形边快照，不重新抽取DEM。

零加权迟到已有可行解，所以该第一层目标达到0。在这个最优面中求最短完成时间；不声称题目把全部普通物资期望时间规定为硬约束。

## 2. 路线松弛

根下界聚合为53类(服务区、物资、质量、体积)，移除箱级期限。每次有货停靠模式枚举该站全部容量合格数量组合。整趟允许重复访问，跨次同类总量可以超过该类需求；主问题仍满足需求等式。这是放宽列集合，不是删去原方案。

原边时间向下取整为毫秒，再求有向全对最短路闭包。对每个整数剩余质量，原边能耗向下取整为0.001kWh单位，再求闭包；每趟预算向上取整。闭包时间/能耗均不高于原边且能耗随载荷不减。两种闭包路径不要求相同，因为下界只需要分别不高估。

原合法架次在保留有货停靠、合并连续同点服务、略去纯经停后，均映射为不更耗时且不更耗电的松弛路径。省去空站/重复基础交接只降低成本；所有真实交付箱数、质量、体积都保留。定价从不采用原模型每区最多访问一次的假定。各次有货模式重量严格为正，故反向资源状态网络有限。

主问题选择非负实数列x，满足各类需求，及每机型 sum(p_r*x_r)<=n_g*T，最小化T。原完整调度映射后的整数列选择必然满足这些约束，因此LP最优值为原问题下界。详细电池恢复和飞机排班仍被放松。

## 3. 完整定价

反向状态为(累计质量、累计体积、路径首节点)，标签为(累计低刻度能量、整数约化成本)。向前增补一次交付使质量严格增加。相同状态下能量和成本都不大的标签可支配另一个，因为未来模式集合不依赖已经使用的箱号。该支配只用于已声明的松弛。

需求对偶pi向下、工作量乘子mu向上取10^7整数刻度。完整定价返回min[mu_g*p_ms-1000*pi*a]。负成本时统一减小每箱pi，确保每条非空列成本非负。归一化分母至少为sum(n_g*mu_g)。整数分子/分母给有效有理数界，不把有限RMP目标直接当成完整问题下界。

## 4. 分支与全局界

每个真实方案的机型架次数和机型分配货类数量必须整数。按非整数值v分成<=floor(v)和>=floor(v)+1两支，互斥且穷尽原整数域。节点定价加入对应行乘子；修复后重新验证三种机型全部松弛列约化成本非负。

下界取所有开放和终止区域下界的最小值，不取某个节点的最高界。本轮500次分支后有501开放区域。独立检查完整1001节点树，并选取250份证书构成覆盖根域的截集；逐份重新执行三种机型定价共750次，得到保守发布值5390.423694秒。

这种树只要求汇总计数整数，列变量仍可分数；完整原路线整数化与电池排程尚未证明。即使该部分树将来关闭，也不能仅因此声称原问题已全局最优。

## 5. 数值和证据的限制

对偶有理数证书针对已构建的数值表；原边来自有限精度地理和物理数据，不是实飞精度保证。代码对量化边、单调性、闭包进行检查；定价器另外与小规模完整前向枚举比较。测试数量不等于物理实验数量。

新23架次来自仓库v2，不是本轮新搜索所得。实际可行上界5693.231489105107秒，23趟，66.25206856269288kWh。原模型的最终区间为5390.423694至5693.231489秒，gap约5.318733%。时间、能耗及资源上界均从真实任务重算，而非下界松弛方案。
