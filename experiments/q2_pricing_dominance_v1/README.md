# Q2 定价与支配加速实验 V1

基线：`main@c3ae26996c0e71cda066533b7ec33e9e142e3b9a` 的 Q2-EVIDENCE-V7-FOCUSED。

目标不是改变原模型或抬高下界，而是检验一种**安全的未来无关状态压缩**是否能减少完整定价标签数。

## 规则

在固定的 (已用质量, 已用体积) 状态下，如果某个 subset-row parity bit 已经不可能被任何剩余容量可容纳的停靠模式翻转，则该 bit 对所有未来延伸都不再有影响；elementary 定价中，同理只保留未来仍有容量机会访问的站点记忆。

因此支配比较使用：
- `mask & livecut(weight,volume)`
- `visited & livesite(weight,volume)`

质量与体积在反向标签扩展中单调增加，所以一旦某 bit/site 因容量不可达，后续不会重新变为可达。该实验只改变标签等价/支配判定，不改变路线可行性、能耗或 reduced cost 公式。

## 实际复跑

从 V7 已发布证书审计中选取历史定价耗时最大的 30 个叶证书，在同一机器、同一证书、同一对偶值下依次运行原定价器与加速定价器。

- 30/30 节点相同；
- 三机型最小整数 reduced cost 在全部 30 节点上逐项一致；
- 标签总数：32,562,316 → 26,163,250，减少 **19.6518%**；
- pricing 内累计时间：24.4421 s → 22.8125 s，减少 **6.6672%**；
- 端到端30节点复核：24.7077 s → 23.0561 s，减少 **6.6846%**；
- 30个节点中29个更快；节点时间降幅中位数约 **6.3547%**；
- 加速包 29 项单元/回归/定价微例测试全部通过。

完整810叶覆盖证书的加速版全量重定价在本轮工具墙钟预算内未完成，因此**没有**用本实验更新5433.956428 s正式下界，也没有声称全局证明更强。

## 论文可用结论

可以写：对最困难的30份已认证定价实例，容量单调性驱动的未来无关状态压缩在保持最小约化成本逐项一致的前提下，使标签数减少约19.65%、同机复跑定价时间减少约6.67%。这说明“不可达性/未来无关状态”值得作为定价工程优化。

不能写：全树必然加速6.67%；全局下界已提高；该支配规则已在全部证书上完成重新认证。
