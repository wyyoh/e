# Q3 可行域/关键区间引导候选实验 V1

基线：当前 `main@c3ae269…` 对应的 Q3-FINAL-V1；正式主方案不修改。

## 实验问题

已有V3鲁棒空间搜索在北侧中继附近生成578个局部候选。我们把“昂贵的完整几何+联合排程”之前的候选筛选看作两阶段搜索：

1. 用关键通信点上的系统最小裕度作便宜筛选/排序；
2. 对高分且空间不重复的候选，再运行完整几何与联合资源排程。

这不是把FSO/PRM通信模型照搬进本题；所有margin和完整核验仍使用本题既有RF/DEM模型。

## 候选富集效果

578个候选中，只有66个的关键点采样裕度达到0.5 dB，占 **11.42%**。

若从同一候选池无放回均匀随机抽样，至少命中一个0.5 dB屏幕通过候选的概率为：
- 1次：11.42%
- 3次：30.54%
- 5次：45.58%
- 10次：70.56%

原V3的“裕度排序+35 m多样性”前三个候选采样分数分别为0.5681、0.5607、0.5554 dB。历史完整联合试验中，前两个虽然几何屏幕通过但未排出联合见证，第三个得到完整0.5 dB可行见证。这说明筛选能把搜索集中到有希望区域，但不能替代联合排程。

为作一个可复现的均匀抽样pilot，固定seed=20260925从同一578候选池取6个候选；六个采样分数均低于0.5 dB，因此在进入昂贵联合排程前即可淘汰。这个单seed结果只用于演示富集，不作为统计显著性证明。

## 重要边界

- 该实验不替换Q3-FINAL-V1的time主方案；
- 关键点采样裕度不是连续通信证明，也不是资源排程可行性证明；
- 历史0.5 dB候选属于V3搜索证据，正式Q3仍由冻结release与final gate管理；
- 本实验没有重新扩展候选域，因此旧5755有限域下界也没有因为本实验而改变；
- 若未来加入新的位置，原四中继有限域下界必须重新核验，不能自动沿用。

## 结论

可行域/关键区间引导的价值主要体现在**减少昂贵候选评估的浪费**，而不是直接改善正式方案。本次pilot支持将其作为搜索加速策略；是否能在相同总预算下稳定找到更高裕度或更短工期，需要更大规模的配对候选预算实验。
