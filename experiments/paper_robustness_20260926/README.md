## 关键结论与范围

Q1基准精确再现18架次/59.131296022053 kWh/546.266929148593 min。原解安全余量20%至23.08834976366333%保持可行及原词典序最优。Q2原方案能量容忍约0.121877%统一正偏差；更小的能耗增幅已经可能破坏原电池衔接。Q2短预算20次均可行，但未达到历史正式工期；起点本来可行，不把20/20称为从零成功率。

Q3原工期优先方案在所测正损耗、正上线延迟中失去连续通信。增强保障备选在0—0.25 dB网格均通过。固定几何下判据随损耗单调，故此备选在该区间可行；该结论不适用于位置同时改变。上线延迟不是速度变慢或额外悬停；修复中保持飞行物理代价、允许推迟出发与服务结束，少数能耗略下降来自减少早到悬停。

Q4原选定两组需求逐项不高于其他两分区，且总配置更少，因此对任意非负库存，在固定日程/关系和缺口-总配置-CV词典序下仍胜出。这是完整枚举向量的单调性推论，不是把17点试验外推为一般稳健性。
