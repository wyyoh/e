# Q2 跨资源链协同重构实验 V1

基线：`main@c3ae269…` 的23架次方案，makespan 5693.231489105106 s。

从最后返航的B型飞机U06开始，取其任务链 [3,16,18]；加入同一最终服务区S008的竞争B任务17，以及两条最后完成的C型任务11、12，形成6个任务、23个货箱的跨链邻域。

每个目标任务允许从原任务移出最多3箱、从联合池加入最多3箱、重新选择A/B/C机型，并在最多4个服务区时枚举全部访问顺序。其他17个任务保持不变。实际生成11,603个目标任务选项。

随后建立一个对真实调度**乐观**的0-1最小最大飞机工作量模型：保持80箱恰好一次并重新分配兼容实体飞机，但放松电池、详细顺序和逐箱截止。因此，该模型的最优makespan不会高估这个有限邻域中任何真实可执行方案的最短makespan。

复跑结果：35,727变量、11,725约束、111,165个非零元；HiGHS 69个节点后得到gap=0。该乐观模型的最优值恰为5693.231489105105 s，与当前真实方案相同。因此，在这个明确的有限邻域内，不存在严格改善当前工期的可执行方案。

这不是整个Q2的全局证明。它排除了一个自然但有限的“把关键B链工作搬给C/A并联动重组”的方向，说明若继续改善上界，需要跨越更大的任务结构，而不是继续同类小交换。
