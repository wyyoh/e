## 不可混淆

1. 62个严格箱子等价类下，容量合格多重集A=13639、B=55247、C=148208452808；这不是能源可行架次数，还没有排列访问顺序。

3. 下界允许重复箱类、非连续回访和最短路松弛，放松每趟能源、期限和电池时间表。这些只用于扩大下界可行域，不能当成实际路线。
4. LP/MILP松弛里的可行值不是原问题的可行上界。120秒流MILP未闭合；该松弛的数值下界约4769.229秒。
5. 12.36%是不确定区间，不是保证还有12.36%的实际改进空间。
6. `snapshot.json`是此前已核验的原始字段、240方向几何和上界任务的规范化快照。本轮不重新提取DEM，也不证明现实测绘/实飞精度。上游ZIP的SHA256随快照保存。
