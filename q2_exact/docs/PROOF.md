# 下界证书的含义与证明

## 上界与目标
所有原优先系数正。按既定模型构造了一份硬时限、普通期望均满足的80箱解，故加权迟到非负下界0已经达到。在第一目标最优的解中研究最晚返航T。
上界重放固定的飞机/电池前驱次序。几何、速度按输入十进制数转为Fraction，所有阶段时间不取整；仅充电安全上界向上至1ns。对q/Q开根，以isqrt生成有理数上界，再取航程下界、能耗上界。所有截止和能源判断以有理数完成。得到T <= 5903.038155秒（标量上界向上至微秒，不声称飞机改变巡航速度）。

## 为什么列生成求的是下界而非真正的新排班
一列保存机型、各类交付计数a、工作时长p、能量e。主问题为

min T;
  sum_r a[j,r] x[r] = d[j];
  sum_{r:type=g} p[r] x[r] <= F[g] T;
  sum_{r:type=g}(e[r]-budget[g]) x[r] <= 0;
  sum_r crossing[r,S] x[r] >= R[S]; x>=0.

其中R[S]=max(ceil(M[S]/80),ceil(V[S]/250))。所有真实计划映射后满足这些必要条件。删去具体排班、截止、每列不能重复同一实物箱以及逐趟电量约束，扩大可行域；主问题的分数列不能当成实际架次执行。

定价允许重复访问同一地区、重复箱类；每次正交付仍消耗至少3kg和12L，因此按累计质量/体积递增构成有限DAG。只合并/排除**相邻同地点正交付**：在这个已删除截止的下界模型中，可以合并为一次、减少固定交接，且合并数量不超过真实初始货物或该区库存。不是禁止i→j→i。

允许两次正交付间使用最短时间闭包（也允许无交付途经节点），时间不大于真实原直线航段之和。这个闭包仅用于下界，不能作为上界路线。容量割按正交付序列越出S的次数计算；每次进入期间最多载80kg或250L，原始整数计划的跨界数必须至少R[S]。

## 不依赖浮点求解器状态的对偶校验
最终聚合能量乘子为0，因此已发布有理数证书只需时间/容量模型。
设lambda[g]>=0，sum F[g]lambda[g]<=1，箱类对偶pi[j]，容量割乘子sigma[S]>=0。
对每一列r，需要
  lambda[g] p[r] - sum_j pi[j]a[j,r] - sum_S sigma[S]crossing[r,S] >= 0.
则任何原计划满足
  T >= sum_j pi[j]d[j] + sum_S sigma[S]R[S].

以10^8缩放对偶，以10^6缩放时间。时间系数使用Fraction向下取整、再用整数Floyd最短路；将上述条件在有限质量/体积DAG上完全定价。整数运算事前检查溢出界。必要时统一降低pi，使三个机型的最小约化成本均非负。所得整数证书独立检查输入哈希、需求、容量割右端、对偶预算与每列约化成本。结果为：

T* >= 51732737979 / 10000000 = 5173.2737979秒。

这比仅声称“有限列池解为5173秒”强：对未加入主问题的所有松弛列也重新定价。仍不能闭合到上界5903.038155，因此不构成原问题的最优性证明。

## 范围限制
证书证明的是已确定十进制几何、参数、能耗推导与准备流程下的数学范围。能耗上界包络源自既定公式，并非验证公式为真实飞行的无误差模型。未实施完整80箱原问题branch-price-and-check。已执行的整数流模型是下界松弛，不能把其可行目标5532.879982当作新的原问题可行上界。
