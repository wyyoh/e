## 最优性证据

- 第一层加权迟到的全局最优值为 0，因为目标非负且已有真实可行解达到 0。
- 当前推荐的完成时间上界：
  `UB = 5693.231489105106 s`
- assistant V5 对 V4 覆盖证书重新定价后保留的有效下界：
  `LB = 5414.564006 s`
- 对应：
  `(UB-LB)/UB = 4.8947154817%`

因此当前可报告：
`5414.564006 s <= T* <= 5693.231489105106 s`

**不得宣称 makespan 已证明全局最优。** q2_closing 的 330 个定向邻域与 assistant 的扩展 MILP/ALNS 都没有找到更短可行解，但有限邻域搜索不能替代全局证明。

## 瓶颈解释

q2_closing 对固定 23 个任务精确枚举两架 B 型飞机的任务分配，得到固定任务下界恰为 5693.231489105 s；现有排班达到该值。因此保持当前 23 个任务的箱组、机型与路线时，仅重新排序不能继续缩短 makespan。进一步改善必须改变跨任务组批、机型或路线结构。
