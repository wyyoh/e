# Q4 模型与证明范围

冻结Q3 time方案的组批、访问顺序、绝对任务时刻、中继位置、服务时段和实际通信保障关系。

**严格主模型：** 原逻辑中继任务不可跨组复制，因此运输关联与实际中继保障关系共同生成3个不可拆块；两组和三组分别只有3种、1种无标签合法分区。

**复制敏感性：** 只保持运输关联块不可拆。若原中继任务服务了多个组，则为每个被服务组复制一整趟中继任务，完整重复准备、飞行、建链、悬停、返航、周转、充电和能耗。该解释改变逻辑中继任务数，只作反事实敏感性。

对组g、资源类型p，固定占用区间为[start, release)，配置需求
`n_gp = max_t sum_j 1{t in I_jp}`。
在同型资源可替换、任务固定且无额外配对/转移限制时，峰值既是必要下界，又能由最早释放优先的区间着色构造达到，因此就是最少数量。

总需求 `D_p=sum_g n_gp`，库存缺口 `G_p=max(0,D_p-I_p)`。不同类型不能互换。主选择顺序为：分类缺口计数 → 配置计数 → 工作量CV → 规范ID，同时保留异构缺口向量上的非支配集。

复制情景下将总资源增加分解为：复制任务本身导致的容量增量 + 同样复制工作量下因禁止跨组共享造成的池化损失，避免把两者混称为共享损失。
