# Q3-CLOSING-V3：模型与证据边界

继承最终Q2的原始输入、物理公式、箱号、AEQD几何、DEM、机型、能源及通信参数。Q2只读。联合完成时间是运输与中继所有架次最后返航的最大值，最终一次返航后的充电不计入完成目标、但计入资源占用与Q4资源核算。

本轮主搜索维持80箱零加权迟到；医疗及首批硬截止额外保留30秒余量。中继位置、时段、实体中继机、能源组件和运输资源联合排程；候选筛查后仍需连续通信区间与临界端点复核。

时间改进来自关键电池前驱换箱：S001两趟C型任务交换一箱医疗物资与一箱饮用水，任务02载荷64→53kg、充电1528.177480→1471.152841秒，关键电池提前57.024638秒就绪；联合工期最终改善54.651611秒，但总运输能耗略增，因此保留不同目标备选。

三中继架次证据：固定运输航迹、5755个明确悬停位置、196个真实保障点的集合覆盖矩阵上，存在总权重3.5且每个候选覆盖权重≤1的对偶证书，因此该有限候选域至少需要4个中继架次；不能推广到连续自由选址。

通信裕度：对固定新四点布局与运输轨迹，取得0.55dB额外统一损耗可行见证，几何放松上界0.555382021dB，因此条件最优裕度位于[0.55,0.555382021]dB。该区间不是自由三维选址的全局上界。
