# 算法与可复现执行

## 数据流

`data/raw` → `model/io.py` → `model/geometry.py` → `model/physics.py` → 模式 → MILP / DP → 输出 → 独立检查 → 最后的 regression。

求解代码不读取历史目标或历史分配。`tests/regression_targets.json` 只允许最终回归读取。所有主输出都能从原始 XLSX、TIF、MAT 重新构建；原 DOCX 和地理说明 PDF 一同存档。

## 几何

AEQD 投影直线连续反变换后的轨迹，逐栅格边界 Brent 根求交；每个开放区间取一点确定恒定像元归属，边界点检查全部相邻闭像元。独立算法使用 GeographicLib Direct + 二分条带逆像，再求行列时间区间交集，算法和地理库均与主路径不同。0.25m采样只用于辅助检查。绝不将 thin Bresenham 当作完整像元集合。

## 安全载荷

端点检查后 Brent，独立70步二分。能耗随载荷严格递增的证明见数学模型文档。额定载荷端点可行就直接返回额定载荷，空载不可行则返回不可执行状态。

## 箱子模式与数量 DP

DP 对每区各物资类别枚举 0..需求数量的笛卡尔积，去掉空集，并逐机型检查额定质量和总体积；能耗和时间由质量、箱数决定。分类压缩前检查同类属性完全相同。

状态 r 是剩余数量向量。选第一个非零类别 k，枚举含 k 且 a_p≤r 的模式，然后转移到 r−a_p。每个可行分区都能先取含 k 的某一批，归纳可知不遗漏分区；这个约束只去掉架次排列对称。单目标标签用于词典序和独立最短累计时间；多目标标签保存全部不被支配的三元组及回溯路径。状态数至多 Π_k(n_k+1)，每个转移消耗至少一箱，无循环。

全局解是15个互不耦合局部解的组合。词典序各层可分解；完整 Pareto 逐区卷积并剪枝。能耗非常接近的标签按显式容差处理；另以零容差复算验证最终向量集合未变化，而非宣称数学无限精度。

## 独立 MILP

`solver/milp.py` 独立枚举各区全部非空原始箱号子集，不调用数量模式生成器。原始箱级二元 set partitioning 已对15区跑完4个目标阶段，原始日志位于 `solver_logs/full_box`。默认快速复现采用从箱子子集得到的严格等价对称压缩，计数模式允许多个二元副本。记录变量、约束、status、gap、dual bound、原始目标缩放因子、耗时、节点数和选中箱号。

独立核对 min N、固定 N 的 min E、固定 N/E 的 min T、无 N 限制的 min T。失败或限时会保留日志并报错，不当成不可行，也不宣称最优。完整箱级重跑可通过 `run_all.py --full-box-milp` 开启，通常比对称压缩慢得多。

## FFD 对照

排序1：质量降序→体积降序→箱号；排序2：体积降序→质量降序→箱号。逐箱放入第一个质量、体积和能源均可行的已有架次，否则开新架次。分别在固定A/B/C和混型场景运行。混型新架次策略显式为额定载质量降序、体积降序、机型编号；不事后用精确解改写 FFD。FFD 是启发式 baseline，不是最优性证明。

## 全事件敏感性

模式的 rho 不依赖 alpha，故事件间可行集合严格恒定。依次删除刚跨过阈值的模式，仅重算受影响服务区的 DP，然后组合其余局部最优值。对所有事件检查阈值自身，真正改变全局最少架次的事件额外在两侧重新求解所有区。`reserve_segments.csv` 合并相同最少架次区间；`reserve_optimal_segments.csv` 另列词典序最优模式改变区间。空值表示整个80箱任务不可行，不表示0架次。

## 运行

在此目录执行 Python 3.11 环境下的 `python scripts/run_all.py`；完整命令、目录、参数见 README。默认从原始输入重算，没有读取“pass=true”捷径。`python scripts/validate.py` 单独重新验证数值和每箱分配。`python -m pytest tests -q` 执行正常、独立交叉与负例测试。`python scripts/reproduce.py` 在独立输出目录重跑并逐字节比较确定性结果，求解器耗时及可互换箱子代表不作为字节一致要求。
