## 运行

需要Python 3.11以上、g++（C++17）和所列数值依赖。本轮环境Python3.13.5；版本见manifest。

```bash
python -m pip install -r requirements.txt
python src/run_stages.py --check-only
python src/run_stages.py
python src/run_stages.py --search
```

- `--check-only`：重建固定输入，编译定价器，独立核对上界、微例穷举及已保存整数证书。
- 无选项：重新执行所有下界列生成；并非只读取已有结果。
- `--search`：另重跑有限池主问题90秒和固定任务排程120秒。不同运行环境可能产生不同候选；任何新上界必须另经`verify_upper_bound.py`检查。

## 文件与版本管理

- `data/encoded/*.b64`：无损压缩数据的文本分片，启动器自动解码成ZIP并展开instance/baseline JSON，再核对SHA256。只有固定数据编码，**源码以普通文本逐文件管理**。
- `src/`：枚举诊断、完整松弛定价、整数主问题、精确排程、独立验算与入口。
- `tests/`：定价穷举对照和错误注入。
- `results/`：冻结证书、求解记录和明确范围的结论；完整轨迹/列池由程序重建。
- `logs/`：运行日志；限时不是不可行证明。
- `manifest.json`：输入身份、上游档案和软件版本。
- `docs/EXPERIMENT_V1.md`：松弛、对偶证书、候选排程以及尚缺的原问题证明环节。
